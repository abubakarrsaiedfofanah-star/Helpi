# Helpi GUI & Responsiveness V14

Applied to the Helpi mobile frontend and Next.js admin interface.

## Mobile app
- Refreshed Material 3 theme with consistent Helpi colors, spacing, touch targets and button states.
- Added responsive constrained content behavior for larger screens.
- Improved desktop/tablet navigation with adaptive NavigationRail and compact mobile NavigationBar.
- Improved login/register responsiveness for narrow phones.
- Added loading-state button behavior instead of ambiguous waiting text.
- Improved cards for long titles/categories and narrow widths.
- Added focus-visible and interaction-friendly controls through Flutter Material components.
- Preserved existing Helpi flows, security, verification, payment and global features.

## Admin
- Added responsive interaction polish for touch devices.
- Improved focus-visible states, active states and disabled controls.
- Added mobile spacing and action wrapping improvements.
- Preserved existing admin workspaces and security/country/media functionality.
