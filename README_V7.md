# Helpi v7 — Responsive Modernization

This release improves the existing real-app foundation without replacing the security architecture.

## Highlights
- Responsive Flutter navigation: bottom navigation on phones, NavigationRail on larger screens.
- Responsive Home actions that switch from rows to stacked cards on narrow displays.
- Modern responsive Admin web console with desktop sidebar and mobile drawer.
- Mobile admin tabs for small screens.
- Adaptive dashboard metrics and two-column/one-column transitions.
- Security-first visual hierarchy: verification, fraud, safeguarding, payments and auditability.
- Improved typography, spacing, cards, status indicators and quick actions.

## Run admin
```bash
cd admin
npm install
npm run dev
```

## Run Flutter
```bash
cd frontend
flutter pub get
flutter run
```
