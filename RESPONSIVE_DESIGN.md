# Helpi Responsive Design

Helpi now uses adaptive layouts across phone, tablet and desktop/web sizes.

## Breakpoints
- < 560px: single-column actions and compact controls.
- 560–899px: phone/tablet layout with bottom navigation.
- >= 900px: desktop/tablet landscape layout with persistent NavigationRail.
- Admin web: sidebar on desktop, drawer + horizontal tabs on smaller screens.

## Security UX
Responsive layouts never hide critical security controls. Security, notifications,
privacy and emergency actions remain reachable on small screens.

## Accessibility
Controls use semantic Flutter buttons, labels/tooltips where applicable, large
interactive areas, Material 3 navigation and adaptive density.
